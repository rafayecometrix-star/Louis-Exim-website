# Louis Exim — Premium Leather Goods & Safety Footwear

Official web application for **Louis Exim**, a premier manufacturer and exporter of handcrafted leather belts, safety footwear uppers, leather keychains, and custom accessories based in Kanpur, India.

---

## 🌟 Key Features

- **Luxury Aesthetic Design:** Curated navy (`#011844`) and warm amber/tan (`#C2B5AD` / `#D4AF37`) palette with Playfair Display typography and smooth scroll animations.
- **100% Mobile Responsive:** Optimized grid layouts, fluid aspect-ratio image swatches (`object-contain` / `object-cover` without clipping), and animated mobile drawer navigation.
- **Interactive Product Showcase & Search:** Real-time search across 7 signature belt categories (Casual, Formal, Reversible, Beaded, Hand-Tooled, Hand-Braided, Polo/Gaucho), Safety Footwear (Open & Strobel Upper), and Leather Keychains.
- **Product Quick View Modal:** Click any product to view full specifications, material details, MOQ (5,000 pcs lot), OEM branding options, and instant inquiry buttons.
- **Direct WhatsApp Inquiry Integration:** Floating pulse WhatsApp button (`+91 9569601581`) for instant international buyer queries.
- **Resilient Inquiry Form:** Server function with Supabase database integration and automatic client fallback mode.
- **SEO Optimized:** Semantic HTML5 elements, descriptive meta titles & OpenGraph tags for search engine visibility.

---

## 🛠️ Tech Stack

- **Framework:** [TanStack Start](https://tanstack.com/router) + React 19 + Vite
- **Styling:** Tailwind CSS v4 + `tw-animate-css`
- **Icons:** Lucide React
- **Database / Backend:** Supabase JS SDK + TanStack Server Functions

## 🚀 Getting Started

### 1. Installation

```bash
npm install
# or
bun install
```

### 2. Development Server

Run the development server locally:

```bash
npm run dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal) in your browser.

### 3. Production Build

To test or generate production assets:

```bash
npm run build
```

## 🐙 Pushing to GitHub

Follow these steps to push your project to a GitHub repository:

### Step 1: Initialize Git (if not already initialized)

```bash
git init
git branch -M main
```

### Step 2: Stage and Commit Changes

```bash
git add .
git commit -m "feat: complete responsive Louis Exim website with product quick view, mobile navigation, and WhatsApp inquiry"
```

### Step 3: Link Remote GitHub Repository

Replace `YOUR_GITHUB_USERNAME` and `YOUR_REPO_NAME` with your actual GitHub repository details:

```bash
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
```

### Step 4: Push to GitHub

```bash
git push -u origin main
```
